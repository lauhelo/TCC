Teste de software

Tela inicial (home)
É necessário fazer login para poder interagir com o site.

Botão "Cadastrar/Entrar"
Vai para a tela de login. Se a senha ou o e-mail estiverem incorretos, aparecerá um alert informando que o e-mail ou a senha estão incorretos. Ou seja, os dados precisam estar vinculados ao banco de dados de cadastro para que você possa acessar o site.

Se os dados estiverem corretos, você será direcionado ao site. Se o usuário logado for uma instituição, ele será direcionado para a página de ONG do usuário, onde poderá escolher qual ONG deseja administrar, de acordo com o cadastro de ONGs. Caso o usuário possua mais de uma instituição, ele poderá adicionar mais de uma.

Botão "Redefinir senha"
Vai para a tela de criação de nova senha. Se a palavra-chave ou o e-mail estiverem incorretos, aparecerá um alert informando que o e-mail ou a palavra-chave estão incorretos. Ou seja, os dados precisam estar vinculados ao cadastro para que o usuário possa acessar o site.

Com todos os dados corretos, ao clicar em "Atualizar a senha", o usuário será direcionado diretamente para a tela de login, onde deverá preencher os dados corretamente com a nova senha para conseguir acessar o site.

Botão "Cadastre-se"
Vai para a tela de cadastro. Se o usuário não tiver conta, ele deve clicar em "Cadastre-se", sendo então enviado para a tela de cadastro.

Nessa tela, o usuário deverá preencher todos os campos corretamente, de acordo com seus dados pessoais. Na parte do e-mail, se não houver o símbolo "@", será exibido um aviso informando que ele é necessário.

Há também um botão para escolher se o cadastro é de uma ONG ou não.

Se escolher que é um usuário (que quer adotar), o usuário preencherá os dados solicitados, criará uma senha e, ao final do cadastro, deverá criar uma palavra-chave, que será usada caso precise redefinir a senha.

Se algum campo não for preenchido, aparecerá uma mensagem informando que é necessário preencher o campo.

Ao finalizar o cadastro como usuário, ele será direcionado para a página de login, para que possa acessar o site com o cadastro criado.

Se escolher que é uma ONG, após o cadastro o usuário completará o perfil da instituição. Ao finalizar, será direcionado para uma página com as informações da ONG, onde poderá editar essas informações ou excluir o cadastro. Somente a pessoa que realizou o cadastro poderá editá-lo ou excluí-lo.

Na parte de cadastro de ONG, é possível escolher outra instituição caso o usuário tenha mais de uma, por meio do botão "Escolher instituição". Ao finalizar o cadastro, o usuário será direcionado para a página de gerenciamento de ONGs. Nela, será necessário escolher qual ONG deseja gerenciar; caso não escolha e tente acessar outra parte do site, aparecerá um alert com a mensagem: "Acesso bloqueado: selecione uma ONG na lista abaixo para poder gerenciar o sistema."

No botão "Gerenciar", ele abre a tela inicial do site, permitindo que a ONG cadastrada adicione seus animais, as doações de que precisa e os eventos que estão por acontecer.
